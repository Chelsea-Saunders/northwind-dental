how does apple make their "buttons" look like they'er clear but looking through water?
ChatGPT said:

Apple’s “clear but watery” buttons — especially in iOS and macOS — are created using a visual style called translucent frosted glass (sometimes called blurred glass, vibrancy, or frosted acrylic).

Here’s exactly how Apple achieves that water-like effect, broken into simple concepts:

🌊 Why Apple’s Buttons Look Like “Clear Water”

Apple layers blur, transparency, vibrancy, and highlight lighting in a very specific way.
Together, these tricks make UI elements look like you’re seeing the content through glass or water.

✅ 1. Translucency (You Can See Through It)

The button isn’t opaque — it lets background color and shapes pass through.
But instead of showing the background clearly, Apple softens and diffuses it.

This creates the underwater appearance.

✅ 2. Background Blur (“Frosted Glass”)

Apple applies a Gaussian blur behind the button.

This blur:

  • hides fine details

  • makes colors blend into soft gradients

  • imitates the way water bends/scatters light

This is the core of the “frosted” look.

✅ 3. Vibrancy (Apple’s Secret Ingredient)

Apple invented a special effect called vibrancy, which boosts background colors passing through translucent materials.

Vibrancy does two things:

  1. Dark UI: It brightens colors behind buttons so they glow softly through.

  2. Light UI: It darkens them for contrast.

This creates that rich, watery depth instead of the button looking washed out.

✅ 4. Subtle Internal Lighting

Apple UI elements often have soft inner highlights and shadows:

  • a faint white highlight at the top

  • a faint shadow at the bottom

This mimics light passing through curved glass or water.

It makes the shape feel thick, rounded, and liquid-like.

✅ 5. Semi-transparent Fill Color

Apple rarely uses pure white or pure transparent.

They use:

  • rgba(255, 255, 255, 0.2) for light mode

  • rgba(0, 0, 0, 0.2) for dark mode

The fill color slightly tints the glass so it feels physical.

🎨 If You Want to Recreate the Effect in CSS

Here is a simplified version of Apple’s “glass / water” button:

css
.glass-button {
  padding: 12px 24px;
  border-radius: 20px;
  backdrop-filter: blur(12px);
  -webkit-backdrop-filter: blur(12px); /* Safari */
  background: rgba(255, 255, 255, 0.25); /* translucent */
  border: 1px solid rgba(255, 255, 255, 0.4);
  box-shadow:
    inset 0 1px 2px rgba(255, 255, 255, 0.4), /* top highlight */
    0 4px 10px rgba(0, 0, 0, 0.2);           /* drop shadow */
  color: #fff;
  font-weight: 600;
}

Put this on top of a colorful or blurred background to see the water effect kick in.

✨ In Short: Apple’s “Water Glass” Buttons Work Because of

Visual TechniqueWhat It Adds
Blur (backdrop-filter)Soft, watery distortion
TransparencyLetting background shine through
VibrancyBoosted colors → richer, deeper glass
Soft highlightsLight moving through curved surface
Tinted fillPhysical “thickness”

All combined → looks like looking through clear water or frosted glass.
